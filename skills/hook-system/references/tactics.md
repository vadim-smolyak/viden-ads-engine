# Hook Tactics — the 47-entry frame library · INDEX

A tactic is the **frame of the claim** — canon §3's Frame layer. The trigger inside it is the mechanism (`triggers.md`); the phrasing on top is the container (`voice-patterns.md`). Canon §5 separates tactic from mechanic, format and mechanism — do not blur those.

**This file is the index and nothing else.** The two tables below carry the job, the awareness fit, the primary trigger **and an example shape** for all 47 entries — which is enough to write a hook set for any named tactic without opening another file. Open a shard only when you need an entry's full *Is / Not* boundary, its book variant, or its caution.

**Two sets live here.**

- **Set A — 34 tactics.** Frames keyed to an *audience state*: who is being called out, what they already believe, where they sit in canon §2.
- **Set B — 13 claim patterns** `[T p.37–38]`. Frames keyed to *the claim itself* — they take one promise and manipulate it (its size, its speed, its novelty, its limits). Genuinely a different axis, which is why they are kept as a marked set rather than dissolved into Set A. Eight of the 13 turn out to be the same move as a Set A tactic and carry a pointer instead of a second definition; five have no Set A equivalent and are defined in full. The mapping is the Set B table below.

**Where the full entries live.** Set A is alphabetical, split so one lookup pulls one small file:

|---|---|---|
| `tactics-a-c.md` | 10 | Aspirational · Authority · Belief · Bold Claim · Call To Action First · Challenge · Confession · Contrast · Contrarian · Curiosity |

**Awareness shorthand** — canon §2's five stages. `Un` unaware · `Prob` problem-aware · `Sol` solution-aware · `Prod` product-aware · `Most` most-aware · `Any` = the frame carries no stage signal on its own.

**Trigger names** are the eight in `triggers.md`. Nothing else is a trigger.

**5 new, 8 duplicates.** The five new ones are defined in full in `tactics-claim-patterns.md`. The eight duplicates keep the book's variant inside the Set A entry they match, and appear in Set B as pointers so a search on the book's own wording always lands somewhere.

## The eight duplicates — pointers only

| Book pattern | Same move as | Book variant kept at that entry |
|---|---|---|
| 3. Use an authority | **Authority** | Authority earned by disclosed scale of experience |
| 5. Compare the claim to its rival | **Contrast** | Comparative multiple against a named rival method |
| 7. State the claim as a question | **Question** | "Who else wants…" — presupposed social proof |
| 8. Offer information in the claim | **How To** | The dated informational headline |
| 10. Stress the exclusiveness of the claim | **Bold Claim** | "The only… that actually works" (not Exclusivity — that gates access) |
| 11. Challenge your prospect's beliefs | **Myth Busting** | First-person "I thought X until…" route |
| 12. Call out a solution they currently use | **Warning** | "Don't spend another dollar on X until…" |

Nothing from the 13 is dropped and nothing is defined twice.

## Repairs applied to this ported library

Recorded so nobody re-introduces them.

- **Humor added as the 34th tactic.** `voice-patterns.md` Cluster 10 tagged a template with a tactic that had no definition anywhere. Never carry an undefined tactic name forward.
- **The 13 claim patterns merged, with the mapping made explicit.** Previously the book's set and the tactic set coexisted with no stated relationship, so the same move had two names.
- **Awareness fit stated for every entry.** The source library gave category notes for some tactics and nothing for others. Stages are canon §2's five, everywhere.
- **TOF/MOF/BOF not used.** One awareness vocabulary across the plugin.
- **Vendor promotional lines removed.** The source libraries carried tool marketing inside the reference text.
- **Exclusivity vs Bold Claim disambiguated.** The book's "exclusiveness" pattern is a singularity claim, not gated access; reading it as Exclusivity produces the wrong hook.
