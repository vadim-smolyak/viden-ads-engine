# Visual Formats — the 46-format production library

Format is the **production vessel**: what the ad looks like, how it is built, what medium it lives in. Mechanic is the move inside it (canon §5). Both are needed; either can come first.

**This file is the index and nothing else.** The selection table below carries medium, awareness fit, the pick-it-when condition and the mechanic pairing for all 46 formats — enough to answer "what format should this be?" without opening anything else. Open one shard only when you need a format's full definition, its production note or its constraint text:

| Shard | Formats | When |
|---|---|---|
| `formats-static.md` | 12 static-only | The concept is a photo or a designed still |
| `formats-video.md` | 22 video-only | The concept is a video |
| `formats-either.md` | 12 that run either way | Medium is still open — pick it per canon §4's belief rule |

**Never read more than one shard for one concept.** A `C` in the table means the entry carries a hard constraint (claim substantiation, policy risk, shelf life, or a client prohibition) — read that entry before briefing it.

**Awareness shorthand** — canon §2's five stages. `Un` unaware · `Prob` problem-aware · `Sol` solution-aware · `Prod` product-aware · `Most` most-aware · `Any` = the format is a delivery vehicle and carries no stage signal on its own; the stage comes from what is said inside it.

**Mechanic pairings** name only mechanics defined in `creative-mechanics.md`. Where no defined mechanic fits, the field is absent — that is deliberate. A format with no pairing still works; take the mechanic from the concept.
