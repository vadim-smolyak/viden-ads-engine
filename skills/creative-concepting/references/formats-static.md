# Visual formats — static only (12)

Full entries for the formats named in the `visual-formats.md` selection table. Read that table first — it answers "which format" on its own. Each entry: what it is, awareness fit, what it is best for, the mechanic pairing, and any constraint or production note.

**Awareness shorthand:** `Un` unaware · `Prob` problem-aware · `Sol` solution-aware · `Prod` product-aware · `Most` most-aware · `Any` = a delivery vehicle carrying no stage signal (canon §2). **Mechanic pairings** name only mechanics defined in `creative-mechanics.md`; where no defined mechanic fits the field is absent — that is deliberate, and the mechanic then comes from the concept.

---

### Billboard
**Medium:** Static
**What it is:** Creative styled as large-format outdoor media — billboard, bus shelter, subway wall, highway sign — presented as though it already exists in public space.
**Awareness:** Un–Sol. The frame borrows scale and mainstream legitimacy.
**Best for:** Legitimacy plays. Newer DTC brands that need to read as an established brand.
**Mechanic:** Implied Answer, Social Witness — the public context does the authority work, not the copy.

### Case Study
**Medium:** Static
**What it is:** A narrative built around one or more measured customer outcomes, carried by metrics, charts or documented proof points.
**Awareness:** Sol–Prod. For people deep in comparison who want evidence before they commit.
**Best for:** High-AOV products, B2B-adjacent DTC, brands with real clinical or platform data.
**Mechanic:** Reframe — the data changes what the prospect thinks the problem is.
**Constraint:** Only run with numbers the client can substantiate. Canon §8: no invented statistics.

### ChatGPT
**Medium:** Static
**What it is:** A screenshot or faithful mockup of a conversation inside the ChatGPT interface. The UI must be convincing.
**Awareness:** Prob–Sol. Reads as research rather than advertising.
**Best for:** Products whose problem a person would plausibly type into a search or chat box. Strongest when the prompt in the mockup is the prospect's actual question, verbatim from research.
**Mechanic:** Trojan Horse, Implied Answer — the interface is the disguise, the product is the answer.

### Feature Benefit Callout
**Medium:** Static
**What it is:** Arrows, labels or pinned text calling out two or more features or benefits, anchored to the product image.
**Awareness:** Sol–Prod. Works once the prospect knows the category and wants to know what makes this one worth it.
**Best for:** Products with several visible or mappable advantages — tech, apparel, tools, supplements with legible ingredients.

### Letter
**Medium:** Static
**What it is:** A handwritten or typed long-form note addressed directly to the reader. The format mimics private correspondence.
**Awareness:** Un–Sol. Direct address is disarming, so it can open a cold audience.
**Best for:** Mission-led and founder-led brands; high-empathy categories.
**Mechanic:** Trojan Horse — the letter form lowers the guard, the message sells.

### Native Text Overlay
**Medium:** Static
**What it is:** A casually shot customer or creator photo — deliberately not studio quality — with native-style text as the hook.
**Awareness:** Un–Sol. The in-feed aesthetic reduces ad recognition and scroll resistance.
**Best for:** Almost any DTC category running a UGC-forward look.
**Mechanic:** Implied Answer, Trojan Horse — the casualness is the disguise.

### Notes App
**Medium:** Static
**What it is:** A screenshot of text inside the Apple Notes UI.
**Awareness:** Un–Prob. Reads as unfiltered private thought — something the viewer was not meant to see.
**Best for:** Confessional voice, founder POV, hot takes, "things I wish I knew before" concepts.
**Mechanic:** Trojan Horse, Social Witness.

### Press
**Medium:** Static
**What it is:** Third-party media validation — outlet logos, headlines or pull quotes.
**Awareness:** Prod–Most. A trust signal is worth most when the brand is already known.
**Best for:** Brands with genuine coverage. Premium positioning and high-AOV, where authority reduces perceived risk.
**Mechanic:** Social Witness.
**Constraint:** Real coverage only, quoted accurately.

### Review
**Medium:** Static
**What it is:** One or more actual customer reviews as the central element. Real review text — a star rating alone does not qualify.
**Awareness:** Prod–Most. The last trust signal before conversion.
**Best for:** Products with review velocity and language-rich reviews. Pull reviews that name a specific pain, not "love this product".
**Mechanic:** Social Witness.
**Constraint:** Never edit or fabricate a quote.

### Selfie
**Medium:** Static
**What it is:** Informal front-facing or mirror capture with the creator as the subject.
**Awareness:** Un–Sol. Lowest ad-recognition static there is.
**Best for:** Beauty, wellness, apparel, lifestyle — anywhere "a real person using this" is the whole idea.
**Mechanic:** Implied Answer, Social Witness.

### Statistic
**Medium:** Static
**What it is:** A single numerical claim as the entire creative.
**Awareness:** Sol–Prod. A number only lands on someone who already knows what it measures.
**Best for:** Brands with real satisfaction, sales or clinical data. The number must be specific enough to be credible.
**Constraint:** Hard gate — canon §8. If the number cannot be sourced to the client's own data, the format is unavailable.

### Text Message
**Medium:** Static
**What it is:** An SMS or chat mockup styled as a private thread.
**Awareness:** Un–Prob. The private-message aesthetic reads as unfiltered.
**Best for:** Concepts framed as one friend telling another, or a "did you see this" referral dynamic.
**Mechanic:** Overheard Conversation, Social Witness.
